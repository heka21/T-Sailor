Races start with a countdown run by the race committee using **flags** (the official timing) and **sounds**
(to get your attention).

## The 5-minute sequence (RRS 26)

| Time to go | Signal | Flag | Sound |
| --- | --- | --- | --- |
| **5:00** | Warning | Class flag up | 1 |
| **4:00** | Preparatory | P (or I, Z, U, black) up | 1 |
| **1:00** | One minute | Preparatory flag down | 1 long |
| **0:00** | Start | Class flag down | 1 |

## The preparatory flags

The flag shown at 4 minutes sets the rules for the last minute before the start:

- **P** — normal. If you’re over the line at the start, return and restart.
- **I** — in the last minute, if you’re over, you must sail round an end of the line to restart.
- **Z** — in the last minute, inside the triangle (line ends + first mark) = 20% scoring penalty.
- **U** — in the last minute, inside the triangle = disqualified (unless the race is restarted).
- **Black** — like U, but you’re disqualified even if the race is restarted.

## Recalls and other signals

<FlagSignals />

- **Individual recall** (X flag + 1 sound) — one or more boats were over. If it’s you, go back and start again.
- **General recall** (First Substitute + 2 sounds) — too many were over or it’s unclear. The whole fleet restarts; a new warning signal follows.
- **AP** — postponement. **N** — abandonment. **S** — shortened course.
